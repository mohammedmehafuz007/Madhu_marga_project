# 🐝 Madhu Marga

Madhu Marga is an Android application designed to help beekeepers efficiently manage their apiaries. The app provides hive monitoring, weather updates, inspection tracking, analytics, and AI-powered assistance to improve beekeeping practices and honey production.

## 📌 Features

* 🔐 User Authentication
* 🐝 Hive Management
* 🌦️ Real-Time Weather Monitoring
* 📍 Hive Location Mapping
* 📋 Inspection Records Management
* 📊 Analytics Dashboard
* 🤖 AI Beekeeping Assistant
* 👨‍💼 Admin Dashboard
* ☁️ Cloud Data Storage
* 📱 Modern Android UI using Jetpack Compose

## 🛠️ Technologies Used

* Kotlin
* Android Studio
* Jetpack Compose
* Firebase Authentication
* Firebase Firestore
* Firebase Storage
* Hilt Dependency Injection
* Retrofit API Integration
* Google Maps API
* MVVM Architecture

## 🚀 Installation

1. Clone the repository:

```bash
git clone https://github.com/mohammedmehafuz007/Madhu_marga_project.git
```

2. Open the project in Android Studio.

3. Sync Gradle dependencies.

4. Configure Firebase using your `google-services.json` file.

5. Run the application on an Android device or emulator.

## 🎯 Problem Statement

Traditional beekeeping management relies heavily on manual record keeping, making it difficult to track hive health, inspections, weather conditions, and honey production efficiently. Madhu Marga provides a digital platform that simplifies hive monitoring, improves decision-making, and supports sustainable beekeeping practices.
